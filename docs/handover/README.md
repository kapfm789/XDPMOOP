# Tài liệu bàn giao

Bộ tài liệu cho người nhận hệ thống: cài, dùng, vận hành và trình diễn OISM (task W5-08, W5-09; mục e.4, e.6 và f của đề). Tài liệu thiết kế kỹ thuật vẫn nằm ở các thư mục khác của `docs/`; file ở đây chỉ trỏ tới chúng.

| Tài liệu | Dành cho | Trả lời câu hỏi |
| --- | --- | --- |
| [install-guide.md](install-guide.md) | Người cài, giảng viên chấm bài | Từ máy mới tới lúc đăng nhập được, cần làm gì? |
| [user-guide.md](user-guide.md) | Chủ cửa hàng, nhân viên, thu ngân | Mỗi vai trò dùng màn hình nào để làm việc gì? |
| [deployment-plan.md](deployment-plan.md) | Người vận hành | Đưa vào chạy thế nào, theo dõi, sao lưu, nâng cấp ra sao? |
| [demo-script.md](demo-script.md) | Người trình diễn | Buổi demo đi qua những bước nào, mỗi bước thấy gì? |
